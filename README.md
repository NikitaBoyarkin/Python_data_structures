# Python Data Structures

A tiny study repo with a couple of classic data-structure implementations in
Python. Legacy practice code — no packaging, no tests and no CI.

## What's inside

| File | Contents |
|---|---|
| `linked list.py` | Linked-list implementation |
| `dictionary object.py` | Dictionary-like object implementation |
| `data.txt` | Sample data used by the scripts |

## Requirements

Python 3 only — standard library, no dependencies.

## How to run

```bash
python "linked list.py"
python "dictionary object.py"
```
